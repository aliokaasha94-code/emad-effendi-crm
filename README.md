# عماد أفندي CRM | Emad Afandi CRM ☕👑

> **نظام إدارة علاقات العملاء (CRM) والمبيعات الذكي المخصص لكافيه ومحمصة عماد أفندي (Cafe & Roastery)**.

---

## 🌟 مميزات النظام (Key Features)

- **👑 تصنيف العملاء الذكي (RFM Segmentation):**
  - تصنيف تلقائي للعملاء حسب الحداثة والتكرار والإنفاق (Champions, Loyal, At Risk, Lost).
  - تحديد العملاء الأكثر إنفاقاً وحساب متوسط قيمة الطلب (AOV).

- **⚡ نقطة البيع وتسجيل النقاط السريع (Quick Cashier & Loyalty):**
  - واجهة كاشير سهلة وسريعة تعمل باللمس لتسجيل زيارات ونقاط العملاء فورياً برقم الهاتف.
  - دعم استبدال المكافآت وكوبونات الخصم وقفل الشيفتات اليومية (Shift Closing).

- **📢 إدارة الحملات التسويقية (Targeted Campaigns):**
  - إطلاق حملات واتساب مخصصة بضغطة زر واحدة موجهة لشرائح العملاء المعرضين للفقد أو كبار العملاء.
  - قوالب رسائل تفاعلية ذكية.

- **📊 لوحة تحكم وتقارير تحليلية (Executive Analytics Dashboard):**
  - رسوم بيانية ومؤشرات أداء رئيسية (KPIs) للإيرادات، الزيارات، ومعدلات الاحتفاظ.
  - تتبع ساعات الذروة والمنتجات الأكثر طلباً.

- **🌐 دعم ثنائي اللغة بالكامل (Full Bilingual Support):**
  - واجهة عربية أصيلة بدعم RTL كامل وإنجليزية LTR بنقرة واحدة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, Lucide Icons, Framer Motion
- **Database & Auth:** Supabase (PostgreSQL)
- **Deployment & Hosting:** Cloudflare Pages
- **State & Data Fetching:** TanStack React Query

---

## 🚀 التشغيل المحلي (Getting Started)

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير المحلية
npm run dev

# بناء المشروع للإنتاج
npm run build
```
